Widget Config

Embed Code

By pointing data-api-url to a project-specific public endpoint, the widget only returns answers from that project's knowledge sources.

<script src="https://api.tokamakforest.com/widget.js" data-api-key="YOUR_KEY" data-api-url="https://api.tokamakforest.com/api/v1/projects/YOUR_PROJECT_SLUG/public" ></script>

How Project Scoping Works

In Tokamak Pilot, each project has its own set of knowledge sources (GitHub repos, docs, uploads). When you scope the widget to a project, the RAG pipeline only searches that project's sources.

Replace YOUR_PROJECT_SLUG with your actual project slug. You can find it in the Tokamak Pilot dashboard or via the API: GET /api/v1/projects

Use Cases

• Project documentation sites — Add a widget to your project's docs page that only answers questions about that project

• Product support pages — Scope to a product's knowledge base for focused support

• Team dashboards — Give each team a widget scoped to their project's sources
