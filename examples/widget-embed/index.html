Tokamak Pilot Widget

Embed a chat widget on any website with a single script tag

How It Works

1

Get an API key from the Tokamak Pilot dashboard with the ask scope

2

Add the script tag to your HTML page, right before </body>

3

Done. A floating chat button appears — visitors can ask questions about Tokamak

Embed Code

<!-- Add before </body> --> <script src="https://api.tokamakforest.com/widget.js" data-api-key="YOUR_API_KEY" ></script>

Demo Pages

Each demo page has the widget embedded with a different configuration. Set your API key in the URL parameter: ?key=tk_xxx

Dark Theme Default — dark background, bottom-right Light Theme White background, bottom-right Bottom Left Dark theme, bottom-left position Project Scoped Answers scoped to a single project

Usage Examples

Minimal

<script src="https://api.tokamakforest.com/widget.js" data-api-key="tk_your_key" ></script>

All options

<script src="https://api.tokamakforest.com/widget.js" data-api-key="tk_your_key" data-theme="light" data-position="bottom-left" data-api-url="https://api.tokamakforest.com/api/v1/public" ></script>

Project-scoped (only answers about a specific project)

<script src="https://api.tokamakforest.com/widget.js" data-api-key="tk_your_key" data-api-url="https://api.tokamakforest.com/api/v1/projects/your-project/public" ></script>

Local development

<script src="http://localhost:4000/widget.js" data-api-key="tk_your_key" data-api-url="http://localhost:4000/api/v1/public" ></script>
