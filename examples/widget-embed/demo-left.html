Widget Config

Embed Code

Use data-position="bottom-left" when the bottom-right corner is occupied by other UI elements (Intercom, Crisp, cookie banners, etc.).

<script src="..." data-api-key="YOUR_KEY" data-position="bottom-left"></script>

When to Use Bottom Left

Many websites already have a chat widget, support button, or cookie consent banner in the bottom-right corner. Moving the Tokamak widget to the bottom-left avoids overlap and keeps both elements accessible.

Combining Options

You can combine position with theme:

<script src="..." data-api-key="YOUR_KEY" data-position="bottom-left" data-theme="light"></script>
