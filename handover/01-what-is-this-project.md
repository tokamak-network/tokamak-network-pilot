# What Is This Project?

[← Back to Index](./README.md)

---

Tokamak Pilot is a **RAG-powered knowledge hub** for the Tokamak Network blockchain ecosystem. In plain terms:

- It **ingests** documentation, GitHub repos, websites, and uploaded files from across the Tokamak ecosystem.
- It **chunks and embeds** that content into a vector database.
- Users can **ask natural-language questions** and get AI-generated answers that cite their sources.
- It also provides **semantic search**, **project management**, **roadmap planning**, **code snippets**, **news aggregation**, and a **public API with SDK** so external tools can plug into the knowledge base.

Think of it as "ChatGPT, but it only knows Tokamak Network" — with a full management UI for the team.

The public-facing brand name is **Tokamak Forest** (see `MARKETING.md` in the repo root for brand guidelines).
