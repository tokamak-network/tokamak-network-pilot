# Who Is It For?

[← Back to Index](./README.md)

---

| Audience | How They Use It |
|----------|-----------------|
| **Tokamak team members** | Log in to the web app, ask questions, manage sources, curate content, manage projects |
| **Project leads** | Manage their project's knowledge sources, team, roadmap, and public page |
| **External developers** | Use the public API or SDK to build integrations (bots, widgets, CLI tools) |
| **Community members** | Use the embeddable widget or public project pages to get answers |
