# Landing Page

[← Back to Index](./README.md)

---

**Location:** `apps/landing-page/`
**Framework:** Next.js 16
**Port:** 3002

A single-page marketing site with these sections:
- **Navbar** — navigation
- **Hero** — headline, CTA, ecosystem partner logos
- **Why Choose Us** — value propositions
- **Features** — AI Q&A, code search, projects, SDK
- **Integrations** — integration options
- **How It Works** — step-by-step process
- **Featured Projects** — dynamically fetched from the API
- **FAQ** — frequently asked questions
- **CTA** — call to action
- **Footer** — links and branding

Uses Framer Motion for scroll animations. Dark design with emerald accents.
